# Chapter 3 — Glossary of Key Terms

> **Art Between Matter and Code** · Gianpiero Moioli · Apress 2025

---

| Term | Definition |
|------|------------|
| **Algorithmic form** | A shape generated by executing a set of rules or mathematical operations rather than drawn by hand. |
| **Bézier curve** | A parametric curve defined by control points; used in Blender to generate smooth paths and volumetric gestures. |
| **Bevel depth** | A Blender curve property that gives a 2D curve three-dimensional volume by sweeping a circular cross-section along its path. |
| **Displace modifier** | A Blender modifier that offsets mesh vertices along their normals using a procedural or image texture as a height map. |
| **Emission shader** | A Blender material node that makes a surface emit light of a given colour and intensity, independent of scene lighting. |
| **Fibonacci sequence** | The integer series 1, 1, 2, 3, 5, 8, 13… where each term is the sum of the two preceding terms; governs proportion in natural growth. |
| **Fluid geometry** | A form that is not static but continuously deforming; in Blender achieved with animated Geometry Nodes noise. |
| **Geometry Nodes** | Blender's node-based procedural modelling system, introduced in 2.92 and extended substantially in 4.x–5.x. |
| **Golden angle** | ≈ 137.5°, the angle subtended by the minor arc obtained when a circle is divided in the golden ratio; the key angle in phyllotaxis. |
| **Golden ratio (φ)** | ≈ 1.6180339…, the irrational number satisfying φ = 1 + 1/φ; appears in Fibonacci growth and classical proportion. |
| **Instance on Points** | A Geometry Nodes node that places copies of a mesh object at each point of a point cloud. |
| **L-system** | Lindenmayer system: a formal grammar that models plant branching and growth by recursive string rewriting. |
| **Lattice structure** | An open, skeletal mesh created by converting solid geometry edges into struts; recalls bone trabeculae or coral scaffolding. |
| **Musgrave texture** | A family of multi-octave fractal noise textures (FBM, Hybrid Multifractal, Ridged Multifractal…) useful for geological and organic surfaces. |
| **Noise texture (4D)** | A procedural texture evaluated in four dimensions (X, Y, Z, W); animating the W axis produces smooth temporal evolution. |
| **Phyllotaxis** | The arrangement of leaves, seeds, or florets on a plant stem following the golden angle; produces Fibonacci spirals. |
| **Procedurality** | The property of a form or process generated by an algorithm rather than manual authorship; implies repeatability and parametric control. |
| **Remesh (Voxel)** | A Blender modifier that rebuilds mesh topology by voxelising the volume and re-triangulating; useful for uniform-density lattices. |
| **Subdivision Surface** | A modifier that recursively splits mesh faces, smoothing the result; increases geometric resolution before or after displacement. |
| **Trim Curve** | A Geometry Nodes node that animates the visible portion of a curve from 0 to 1, simulating a line being drawn in real time. |
| **Voronoi texture** | A cellular noise pattern based on the distances to a set of seed points; produces skin-like or cracked-earth surfaces. |
| **Wireframe modifier** | A Blender modifier that replaces each edge of a mesh with a four-sided tube of controlled thickness, creating skeletal structures. |
