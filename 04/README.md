## Scripts (`scripts/`)

One Python script (no Blender required — standard Python 3.x) generating the key conceptual diagram of the chapter.

Full parameter reference: **[scripts/README.md](scripts/README.md)**

| Script | Description |
|--------|-------------|
| `aura_transition.py` | Generates the Aura & Reproducibility diagram as a standalone SVG file |

**Reference diagram** (generated by the script):

| File | Description |
|------|-------------|
| `ref_aura_transition_diagram.svg` | Aura vs. Reproducibility — five phases from handmade object to AI-generated work |

> **Windows:** double-click `run_aura_transition.bat` — runs with the system Python or Blender's bundled Python.  
> **macOS/Linux:** run `./run_aura_transition.sh`  
> **Manual:** `python aura_transition.py`
