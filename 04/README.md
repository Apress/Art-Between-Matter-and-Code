## Models (`models/`)

A demonstration of the **three levels of digital certification** described in §4.2.2, all present in the same folder:

| File | Level | Description |
|------|-------|-------------|
| `metadata_demo.blend` | Level 1 — Internal | Scene with Custom Properties already set (author, title, date, license, version). Open in Blender → Scene Properties → Custom Properties. |
| `metadata_demo.blend.cdm.json` | Level 2 — Certified | SHA-256 fingerprint of the `.blend` file, generated by `certify_asset.py`. Verify with: `python certify_asset.py metadata_demo.blend --verify` |

> Level 3 (on-chain / permanent): run `ots stamp metadata_demo.blend.cdm.json` to anchor the certificate to the Bitcoin blockchain via OpenTimestamps (free, no account needed).
