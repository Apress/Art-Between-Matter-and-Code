## Scripts

| Script | Launcher | Section | Description |
|--------|----------|---------|-------------|
| `fabrication_workflow_diagram.py` | `run_fabrication_workflow_diagram.bat` | §6.1 | Generates the Virtual-to-Physical Fabrication Workflow SVG diagram |
| `print_ready_checker.py` | Open in Blender Scripting → Alt+P | §6.2 / §6.2.5 | Checks active mesh for 3D printability (non-manifold, dimensions, normals) |

**Run (Python):**
```bash
python scripts/fabrication_workflow_diagram.py             # saves SVG in current folder
python scripts/fabrication_workflow_diagram.py --output scripts/../images
```

Or double-click `scripts/run_fabrication_workflow_diagram.bat` — saves to `images/` and opens in browser.

**Run (Blender script):**
1. Open Blender → Scripting workspace
2. Open `scripts/print_ready_checker.py`
3. Select the mesh object to check in the viewport
4. Press **Alt+P** to run

## How to use

- Scripts require **Python 3.x** with no external libraries.
- The Blender script (`print_ready_checker.py`) requires **Blender 4.3 LTS** or later.
- For CDM certification of fabricated artworks, see `04/scripts/certify_asset.py`.
- For 3D scanning protocols referenced in §6.1, see Chapter 5 §5.5.1.
- For lost-wax casting parameters, see App. F (Chapter 5) and App. H (this chapter).
