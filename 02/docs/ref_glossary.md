# Glossary — Chapter 2: Modeling as Creative Gesture

**Boolean operation** — A set operation (Union, Difference, Intersect) applied to two meshes to combine or subtract volumes. Fontana's cuts are reinterpreted as Boolean Difference operations in Blender.

**CNC milling** — Computer Numerical Control: subtractive fabrication process that carves material (wood, metal, stone) guided by a digital 3D model.

**Digital sculpting** — Brush-based 3D modeling that simulates the additive/subtractive gestures of clay modeling. Main tools: Blender Sculpt Mode, ZBrush, Nomad Sculpt.

**Edit Mode** — Blender workspace for direct mesh manipulation: vertices, edges, faces. Equivalent to cutting into the stone once the block is placed.

**Expanded Studio** — The contemporary studio extended into software, virtual platforms, and cloud tools, no longer confined to a single physical location.

**Fluid matrix** — Virtual modeling environment where form is never fixed: shapes can be stretched, deformed, merged or grown without material resistance.

**FDM (Fused Deposition Modeling)** — 3D printing technique that deposits molten filament layer by layer. Common desktop printers use FDM with PLA or ABS.

**gltf / glb** — GL Transmission Format: open standard for 3D models optimized for real-time rendering and web delivery. `.glb` is the binary version.

**Geometry Nodes** — Blender's node-based procedural modeling system, allowing geometry to be generated and modified algorithmically rather than manually.

**Image-to-3D** — AI workflow that converts a single photograph or sketch into an editable 3D mesh. Tools: Kaedim, Spline AI, Luma AI Genie.

**LiDAR (Light Detection And Ranging)** — 3D scanning technology using laser pulses to measure distances and reconstruct surfaces with high precision. Used for large-scale or architectural scanning.

**LOD (Level of Detail)** — Technique that uses simplified mesh versions at a distance and detailed ones up close, optimizing real-time rendering performance.

**Mesh** — The polygon network that defines a 3D object's surface: made of vertices (points), edges (lines), and faces (polygons). The fundamental data structure of 3D modeling.

**NeRF (Neural Radiance Field)** — AI technique that reconstructs a 3D scene from a set of photographs by learning a volumetric representation. Used for photorealistic reconstruction.

**Object Mode** — Blender workspace for arranging and composing objects as whole units: moving, scaling, rotating primitives before working on their internal geometry.

**OBJ / FBX / STL** — Common 3D export formats. OBJ: geometry + materials. FBX: rigged models and animations. STL: geometry only, standard for 3D printing.

**Photogrammetry** — 3D reconstruction technique that derives geometry from a series of photographs taken from multiple angles. Tools: Meshroom, RealityCapture, Kiri Engine.

**Point cloud** — Raw output of a 3D scan: a set of measured surface points without polygon connectivity. Must be converted to a mesh for use in 3D software.

**Polygonal modeling** — Manual shaping of a mesh by moving vertices, extruding edges, and manipulating faces. The foundational technique of 3D modeling.

**PBR (Physically Based Rendering)** — Shading model that simulates real-world light interaction using Albedo, Roughness, Metallic, and Normal maps.

**Procedural modeling** — Form generation through mathematical rules and algorithms rather than manual manipulation. In Blender: Geometry Nodes. In architecture: Grasshopper.

**Raster graphics** — Pixel-based images (JPEG, PNG, PSD). Resolution-dependent. Tools: GIMP, Krita, Photoshop.

**Remesh** — Operation that rebuilds a mesh with uniform polygon distribution, often used to clean scan data or prepare a sculpted model for texturing.

**Retopology** — Rebuilding a high-polygon mesh into a lighter, cleaner structure with better edge flow. Essential before rigging, animation, or 3D printing.

**Sculpt Mode** — Blender workspace for brush-based gestural modeling. Closest digital equivalent to working with clay.

**SLS (Selective Laser Sintering)** — 3D printing technique using a laser to fuse powdered material (nylon, metal). Produces strong, complex parts without support structures.

**Sketchfab** — Online platform for publishing, sharing, and embedding interactive 3D models in a browser. Used for cultural heritage dissemination and creative portfolios.

**Structured light scanning** — 3D acquisition method using projected patterns of light to capture surface geometry with high detail.

**Text-to-3D** — AI workflow generating 3D models from text prompts. Tools: Meshy AI, Tripo3D Rodin, Sloyd AI.

**UV mapping** — Process of "unfolding" a 3D mesh surface onto a 2D plane so that textures can be applied correctly. UV refers to the texture coordinate axes (U = horizontal, V = vertical).

**Vector graphics** — Path-based images defined by mathematical curves (SVG, AI, EPS). Resolution-independent, scalable without quality loss. Tools: Inkscape, Scribus.

**Voxel Remesh** — Blender tool that reconstructs mesh geometry using a voxel (3D pixel) grid, useful for cleaning complex or overlapping geometry after sculpting.

**XR (Extended Reality)** — Umbrella term covering AR (Augmented Reality), VR (Virtual Reality), and MR (Mixed Reality). Platforms: Unity, Unreal Engine, Spatial.
