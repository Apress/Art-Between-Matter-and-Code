# Chapter_1 — Ideas, Materials, Technologies and Aesthetics

> Supplementary materials for **Art Between Matter and Code** by Gianpiero Moioli.

## Contents

| Folder | Description |
|--------|-------------|
| `images/` | Reference images and artworks (e.g. Canova sculptures) |
| `models/` | 3D files (.blend, .obj, .stl) |
| `scripts/` | Python / Blender scripts |
| `docs/` | PDF and supplementary documents |
| `media/` | Videos, animations, renders |

## How to use

- Blender files require **Blender 4.x** or later.
- The document `Neoclassicism_and_Canova.pdf` provides the theoretical background for this chapter.
