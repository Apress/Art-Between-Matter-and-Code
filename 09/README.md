# Chapter_9 — Metaverse as Exhibition Space

> Supplementary materials for the chapter *Metaverse as Exhibition Space* from **Art Between Matter and Code** by Gianpiero Moioli.

## Contents

| Folder | Description |
|--------|-------------|
| `images/` | Reference images, artworks, screenshots |
| `models/` | 3D files (.blend, .obj, .stl) |
| `scripts/` | Python / Blender scripts |
| `docs/` | PDF and supplementary documents |
| `media/` | Videos, animations, renders |

## How to use

- Blender files require **Blender 5.x** or later.
- Open scripts in Blender's Text Editor or run from the terminal.
